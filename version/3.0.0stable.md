## 更新文案

As the saying goes,  
```text
"When it comes to hiring, I'll take a GitHub commit log over a resume any day."
```
这句话的意思是：“在招聘这件事上，我任何时候都宁愿看 GitHub 提交记录，而不是简历。”这充分体现了开源的价值与力量。
受此启发，翱三通史也已全面开源，项目地址：[https://github.com/zfscjch/OrsunHistory.git](https://github.com/zfscjch/OrsunHistory.git)，感兴趣的朋友欢迎前去围观！（建议访问时搭配梯子使用。）

好了，说回正事。**翱三通史官网 v3.0.0 Stable 正式版（稳定版）** 现已正式发布！ 本次更新接入了 DeepSeek R1 大模型，已为**所有同学**自动生成了**个人传记**，欢迎大家前往官网欣赏。
如果对 AI 生成的传记内容不太满意，也不必担心——点击页面下方的“参与编辑”按钮，即可自由修改、定制属于自己的专属篇章。

本次更新的主要内容：
1. 修复了已知的bug;
2. 完善《翱三通史》的相关文章；
3. 添加了“版本查看”页面。
